## 每次讨论五步

1. **明确章次和页码**：仅就用户已上传/明确提供或可合法核读的当段文字研习，未读到不可冒称已知。按原书顺序推进，不主动跳过所谓基础内容。
2. **原说先于判断**：区分实体书印刷正文、用户手写批注、我们的释义及引证文献。可能的错字用疑点记录，不能静默替换。
3. **双向剖析**：用户可用既有经验提出理解、疑义和反证，助手独立推理、查找可核实来源并指出不同路线；双方不因书上写了或一方坚持就定论。
4. **小结验证**：视内容结合实例、反例、图示、手算课式；事实/候选/未决分别记录。确定性起课要有边界和一致性测试，断课经验与客观效力的主张单独审查。
5. **两层归档**：私有校读 Word 文档继续积累阅读与讨论（授权与个人批注仅保留在用户提供的私有材料范围）；公开 GitHub 只存自己的研究摘要、少量合规引文、来源、争议、独立算法和可检验测试。任何未获授权的现代书籍全本、连续大段转录、照片、手写笔记不上公开仓库。

## 术语标准化与可读性规范（2026-11-22，共同约定）

用户在《六壬金针》印刷 p23 遥克法的「支神」用法处明确指出：同一运算对象如果写作多个术语，会增加初学者误读风险。**今后原创研习讲义、公开研究摘要、软件需求与界面尽量采用一义一名、前后一致的通俗标准术语；标准名与历史原词另表映射，不能擅改原书或把限定语境的别名全局等同。**

1. **本书遥克这一具体语境**：原文「四课天盘的支神」在我们自写的算法解释中统一表述为「四课上神（其地支值）」，并明确指选中课的上层地支。单独的「支神」在别书、别段未必同义，不设跨书全局替换。
2. **比较对象和字段清楚**：分别写「四课上神」「四课下位」「日干」「被选课的上神作为初传」，不将一列完整的四课对象与其单独上神混为一谈；可对应程序字段 `lesson.upper_branch`、`lesson.lower`、`day_stem`、`first_transmission`。
3. **同属性须注明是哪一种属性**：本书 p23 多遥克候选所借用的「比用」以候选上神与日干**同阴阳**为比；不能含糊写成「属性相同」以致被误认为五行同类。比较对象限定在已经筛出的蒿矢候选或弹射候选中，不混入别的取传分支。
4. **文献与教学分栏**：原著用词、书页、历史异名如实记录；我们的清晰改写标为现代解释，软件规范只选一套正名。出现无法无损映射的历史术语，则保留上下文及争议，不以统一术语掩盖版本差异。
5. 本约定属于文本编辑与软件数据语义规范，并不声称古书「支神」必为错字、其他用法错误或断课有效性获得验证；旧手写批注仍不读、不录、不上传。
