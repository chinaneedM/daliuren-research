# 《六壬金针》完整共同研习方法 R1（2026-11-18）

## 原始目标

用户已经研习过大六壬，希望**亲自带着助手从头到尾完整学习《六壬金针》**，借共同质询和推演让自己再学深一遍；同时通过系统拆解，帮助项目形成对整门术数的整体性、具体性认识，并为《天问》已有术数及未来其他独立术数提供可重复的**研究方法**，不是直接搬运六壬规则。

## 每次讨论五步

1. **明确章次和页码**：仅就用户已上传/明确提供或可合法核读的当段文字研习，未读到不可冒称已知。按原书顺序推进，不主动跳过所谓基础内容。
2. **原说先于判断**：区分实体书印刷正文、用户手写批注、我们的释义及引证文献。可能的错字用疑点记录，不能静默替换。
3. **双向剖析**：用户可用既有经验提出理解、疑义和反证，助手独立推理、查找可核实来源并指出不同路线；双方不因书上写了或一方坚持就定论。
4. **小结验证**：视内容结合实例、反例、图示、手算课式；事实/候选/未决分别记录。确定性起课要有边界和一致性测试，断课经验与客观效力的主张单独审查。
5. **两层归档**：私有校读 Word 文档继续积累阅读与讨论（授权与个人批注仅保留在用户提供的私有材料范围）；公开 GitHub 只存自己的研究摘要、少量合规引文、来源、争议、独立算法和可检验测试。任何未获授权的现代书籍全本、连续大段转录、照片、手写笔记不上公开仓库。

## 节奏原则

- **完整性**：真正读完整本书，不因有“更重要”的算法工作跳过原书其他部分。
- **深度**：基础概念也愿意拆开讨论，但已确立的共识不必每次重复做深度溯源。
- **可证伪**：完整读过不等于所有主张为真；古籍记载、算法可复现、实际占断效果分层。
- **后续扩展**：《天问》的八字/紫微与六壬继续各自独立；跨学科可借鉴“如何读、如何验证、如何留证、如何编写可测软件”，不能擅自改动核心或混淆术语。
- **对话续接**：先查仓库实时 HEAD 与本文件、状态 JSON 的 current_study_location，再继续原书下一段；不能凭旧对话臆测进度。
