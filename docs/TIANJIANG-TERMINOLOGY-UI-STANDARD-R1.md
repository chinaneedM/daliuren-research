# 天将术语及方形天地盘显示规范 R1（教学／软件设计候选）

日期：2026-11-22。来源：北海闲人《六壬金针》实体印刷 p31–33（用户照片）、双方本轮口头讨论及现有 docs/JOINT-STUDY-METHOD-R1.md。**本文件是我们独立撰写的命名与显示规范，不是原书正文、不是统一古籍流派的强行改名、也不是已完工的软件。**

## 1. 十二天将的统一展示名

按书中十二位的标准次序，软件／现代讲义默认使用：**贵人、腾蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后**。

- 首位展示名为**贵人**，全称和术语注释**天乙贵人**，书内名称**贵神**；历史单字为**贵**。用户明确允许“贵神”或“贵人”任一，首版暂选“贵人”以最容易联系其全称；不得称《金针》p31原表就是如此写。
- 其他天将一律保留完整双字，不在默认 UI 改成蛇、朱、六、勾、青、空、白、常、玄、阴、后等简称。可在原书史料词典索引简称，但不增加用户要额外记忆的默认文字层。
- “腾蛇”字形依本书当前印刷用字；日后若古籍有“螣蛇”异体或术语版本差异，独立登记，不直接替换本文用字。
- 以字段 `general_id` 存稳定身份、`display_name` 存展示名、`source_aliases` 保存书页和别称，不能靠单字简称反推计算对象。

## 2. “对／乘／作／临”与两个明确的映射层

- `general_to_heaven_branch`：**天将对应哪一个天盘支**。当前纸本 p32 的“对”是将贵字**对准天盘支**的摆放操作；“乘”“作”用于表达定位后天将和天盘支的关系。教学主文字固定说“贵人对应天盘亥”。
- `heaven_branch_to_earth_palace`：该**天盘支位于哪一个固定地盘宫位**。纸本 p33 的“临”表达此空间对应，例“亥临午”“贵人临午”可通俗写为“贵人对应的天盘亥位于地盘午宫”。
- 原词注释中仍保留“乘、作、对、临”，并说明“对”偏**定位动作**、“乘／作”偏**天将与天盘支的关系**、“临”偏**地盘位置**。这是该段原文的语境级释义，不声称所有古籍全义等价。
- 尤其不可只存`general=贵人`和`branch=午`而丢失`heaven_branch=亥`，否则“贵人临午”容易被误解成贵人对应天盘午支。
- 未来推荐盘位单元至少可显式查看`earth_branch`（地盘）、`heaven_branch`（天盘）、`heavenly_general_name`（天将）三项；层级标签与计算分离。

## 3. 昼占夜占与贵人起例

当前本书之昼占/夜占按照**选定占时支**判断：卯辰巳午未申为昼，酉戌亥子丑寅为夜。实际问事时间`real_question_time`、正时/活时的`hour_selection_method`、最终所用`selected_divination_hour_branch`、昼夜`nobleman_day_night_class`分别储存；不能把真实钟表时辰无条件代入贵人昼夜判定。

贵人歌诀用于按**日干＋选定占时的昼夜类别**确定贵人所对应的**天盘支**；接着依该天盘支所临的地盘宫位判天将顺逆行。它不是“月将”规则，亦非十二天将各有一套歌诀。

本书 p33 的顺逆分界：贵人对应的天盘支所处地盘若为亥子丑寅卯辰，十二将按规定顺行；若为巳午未申酉戌，则逆行。顺逆判断对象是**地盘宫位**，不是简单把贵人对应天盘支的阴阳或顺序当成顺逆条件。

## 4. 方形十二宫教学盘

借鉴已有十二宫式方盘视觉布局，但大六壬十二宫地盘地支顺序独立核实为：

```text
地盘（固定）
巳 午 未 申
辰       酉
卯       戌
寅 丑 子 亥
```

书内戌将巳时丁亥日的天盘相位（戌将位于地盘巳）：

```text
天盘（和上列地盘逐宫对应）
戌 亥 子 丑
酉       寅
申       卯
未 午 巳 辰
```

因此**地盘午宫的天盘支为亥**；丁日昼占贵人对应天盘亥，说明“贵人对应天盘亥，所在固定地盘为午”。该方盘提供方位可读性、显式三层标注，但**不能因为沿用紫微斗数十二宫视觉设计就混合两门术数的原理**。《天问》确定性排盘核心不改；组件复用须后续语义核验、测试。

## 5. 康熙时期新贵人歌诀：史料未决而不是被裁决的史实

第31页北海闲人叙述康熙时期引用西洋天文知识而另创一套贵人歌诀，但本段未列出处及新歌诀正文。当前仅登记为**现代作者的历史说法**：实际编定者、史料版本、演化与新旧算法优劣应待后来考据；不能用作者讥讽“科学”的语气替代史证。读书阶段继续依本书所选古歌，不立刻争流派。

## 7. p34 天地盘、四课、三传的天将一致性（共同认可的显示标准）

**单一来源**：按日干、选定占时昼夜确定贵人所对应的天盘支，再按贵人对应天盘支所处的固定地盘宫位决定顺逆，最终求出一张 `heaven_branch_to_general`（十二天盘支 → 十二天将完整名称）。此映射仅建立一次。

**三类投影**：

1. **天地盘**：每一固定地盘宫显示`earth_branch`、`heaven_branch`、`heaven_branch_to_general[heaven_branch]`。p33–34印刷把天将写在天盘支外圈、可省固定地盘，是书面展示惯例而非算法删除地盘。我们的默认教学界面反而必须显示地盘。
2. **四课**：第 `i` 课写原来的上下位，并在上神旁显示`heaven_branch_to_general[lesson[i].upper_branch]`；**不是**按课下位或日干重起天将。p34按逻辑序：①子／丁→天后；②巳／子→天空；③辰／亥→白虎；④酉／辰→朱雀。
3. **三传**：初、中、末传各自的**支值**查询同一个映射；p34 巳／戌／卯→天空／腾蛇／太常。天将与传支同时显示，不修改传支，也不重新选择贵人。

**可检验约束**：如果四课某上神与三传某一支相同，二者显示的天将一定相同。例如 p34 第二课上神巳与初传巳同为**天空**。布局从教材式切换至金字塔式或隐藏／显示某标签，值保持不变。

**证据层级**：来源为用户当前逐段口头解释及本书现代印刷 p34，课例具体天将是助手依据已见书页独立复核；软件未实现。本项只是规范，并不能代替预测准确度或古籍其他派起将法的考证。
