# SOFTWARE-0001｜固定天地盘与四课的最小确定性实现（非完整起课引擎）

日期：2026-11-22。本项是《六壬金针》卷一已见规则的**独立软件侧线**；共同研习仍停在第47页，下一段是卷二p48《入手判断的准备工作》，**其正文尚未提供，不得凭本实现宣称已读卷二**。

## 规则来源与版本

- 北海闲人《六壬金针》，用户实体纸书印刷p10–14：固定地盘、月将加占时、十干寄宫和逻辑第一至第四课。
- 同书p33–35：丁亥日、戌将巳时的四课展示；p39–47：第九节《迅捷起课法》，尤其p43方位练习和p46–47甲午日丑将戌时四课。
- 书影只在私人对话核读，具体印次、出版信息未确证；公开仓库没有原照片或大段现代作品文字。书中课例由助手复算，不声称读者已逐例确认。

## 输入与计算范围

只接受用户或上层系统已经选定的`day_stem`（日干）、`day_branch`（日支）、`month_general`（月将支）和`chosen_hour`（占时支）。**不**在此处根据公历时间换算干支，不在此处决定中气换将日期、正时/活时、昼夜贵人、流派版本或时区边界。

固定地盘按子丑寅卯辰巳午未申酉戌亥映射为0至11。天盘相位`offset=(index(月将)-index(占时)) mod 12`；地盘宫位e上天盘支为`(e+offset) mod 12`，逆查地盘为`(h-offset) mod 12`。日干首课起点使用本书十干寄宫，后继课由已固定的同一张天地盘递取；第一课的**书写下位日干**与其**取神地盘寄宫**分别记录，不把地盘宫改名为天干。

模块`daliuren.foundation`现提供`make_plate`与`build_four_lessons`，以及`Plate.heaven_on`、`Plate.earth_under`、`Plate.pairs`。`Lesson.number`为逻辑1至4，传统四课从右向左的界面布局仍由展示层负责，不改变计算字段。

## 测试与覆盖

`python -m unittest discover -s tests -v`本地已通过**8项测试**：12×12即144种月将/占时组合的天盘双射性与逆关系、相同/对冲位置、p43两个正逆定位练习、三组书内四课例（庚子卯将辰时、丁亥戌将巳时、甲午丑将戌时）及非法干支输入。相同占时/月将与对冲只验证相位0和6，**不**声称课体或取传分支已计算。

GitHub Actions既有基础检查增加这一测试命令；成功只覆盖上述基础数学及书内有限案例，不能视为九宗门全法通过，更不能视为断课预测有效性验证。每次需查CI实际运行`head_sha`是否为实时HEAD。
