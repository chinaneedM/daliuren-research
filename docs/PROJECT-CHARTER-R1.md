# 大六壬项目章程 R1

## 一、定位

大六壬独立长期共同研习、历史考据与软件构建。用户已经学过大六壬，持有实体书，双方不是单向授课关系；助手可提出研究建议、核对文献并实现程序，用户参与术理讨论和复核；任何意见都必须经证据和可复现推演检查。

## 二、目标

1. 对大六壬术理从整体到细部重新共同研习：基础、占时/月将、天地盘、四课三传、九宗门、课体、类神、神将、判断方法与课例。
2. 建立历史考据：作品、作者归属、成书/编纂、版本、藏本、影印/数字文本、传承和异文区分。
3. 起课排盘优先实现为确定性、可独立测试的软件；断课辅助可列明判断依据、条件、版本/流派和反证，不等同于已经客观验证预测有效性。
4. 建立可续接的数字资料库和规则档案，争议可保留多个候选，无原页证据不得虚构历史裁决。
5. 独立于《天问》；仅借鉴经过核验的干支工具、十二位置布局和工程方法等，不更动《天问》封闭核心。未来相学、风水等独立立项，目前不开发。

## 三、完整通读与双方学习使命（2026-11-18补充）

**用户明确要求：以北海闲人《六壬金针》为连续主教材，双方从导论起、按目录次序，完整而细致地共同学习整本书。** 这不是“为了尽早造出软件而选学几个功能章节”，也不是单向授课。用户先前学过大六壬，目的是借共同讨论再次深化认识；助手则通过逐段核读、推理、核对资料、构建可复核规则档案，在项目层面逐步形成可续接的完整术理认识。

每一段至少区分：作者原说 / 我们各自的理解 / 支持证据与不同看法 / 需要保留的疑问。遇到熟知基础可简洁但不主动漏章节、不以“这很基础”为由略过；遇到关键理论做细化例证、手工推演与不同版本对照。历史考据是辅助理解的工具，不让枝节检索无限延误通读主线。单段可以分多次讨论，用户节奏优先。

学习过程持续维护两条不同的成果链：**私人逐段校读与讨论笔记**（实体书照片、个人批注和完整现代文字不公开）；**公开仓库中的原创研究摘要、术语、争议、可测试规则与课例结构**（仅保存版权允许的引用/事实）。不以 GitHub 提交数取代学到哪里，也不把软件开发当作通读课程的替代。

### 完整通读后的长远价值

《六壬金针》的完整研习是一次“如何深入理解一门术数”的工作范式试验，供现有《天问》（四柱八字、紫微斗数）及未来其他独立术数研究借鉴研究习惯、证据管理、模块化软件与复核方法。**不能把大六壬的具体断法或起课规则直接推广到其他术数，不以本书替代其他术数原典**；《天问》既定确定性核心保持 CLOSED。

## 四、起点与材料

用户手边两本书为北海闲人《六壬金针》及陈公献《大六壬指南》（华龄出版社）。实体版具体印次、目录、编校与页码未核验。优先获取可依法阅读、引用或存储的数字资料，逐本登记来源授权和版本身份；不要求用户反复拍照。必要时可请求少量原书目录/疑点用于版本核对。

## 五、分层原则

- 典籍原文 ≠ 数字转录 ≠ 现代讲解 ≠ 我们的释义。
- 排盘/取传算法正确 ≠ 断课经验获得客观实证。
- 同名作品 ≠ 同一版；相似规则 ≠ 直接师承；界面布局相似 ≠ 学理相同。
- 程序规则应说明版本、适用范围、输入、输出、测试向量、争议及引用出处。
- 记录事前断课与事后反馈，保护个人隐私；案例数不能替代有效性证明。

公开仓库、零付费优先。常规免费的文件、代码、测试与工作流提交可执行；任何付费、资料购买、账号安全、仓库删除、私有信息公开、权限/凭证/所有权变更均需单独确认。不上传未获再分发授权的现代著作全文与扫描件。
