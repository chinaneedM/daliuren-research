# RAPID-CHART-MENTAL-AND-SOFTWARE-VERIFICATION-R1｜迅捷起课法的确定性校验设计

日期 2026-11-22。依据：《六壬金针》实体印刷 p38–47 及用户当轮提出的“软件替代古人费时手工排盘”观点。**仅为原创研究和测试向量提纲，不是已完成的引擎、验收、历史算法变更或预测效度实验。**

## 目标与层级

传统心算技巧是**位置计算和规则选择的快速表示**，不是一条独立于常规“月将加时→四课→九门选三传→天将”的神秘分支。软件默认金字塔式课式及固定方形十二宫，保持每宫`earth_branch`/ `heaven_branch`/ `heavenly_general`显式全称；教学可分步骤播放但最终结果必须与直接索引法相同。

月将加时统一向量：地盘子丑寅卯辰巳午未申酉戌亥记0..11，天盘 `heaven_on(earth)=(earth+general-hour+12) mod12`；反查询 `earth_of(heaven)=(heaven-general+hour+12) mod12`。心算孟仲季、六冲、三合/六合只作为帮助求同一个置换的另一种表述。书 p40–42 的十二占时说明**固定了月将＝子**，绝不能据此将“某占时永远伏吟/返吟/连茹”硬编码。

## 原书复核案例组（助理独立复算）

**p43练习**：
- 亥将午时，地盘申/辰/子/未上的天盘支 → 丑/酉/巳/子。
- 未将酉时，天盘午/申/亥/卯对应的地盘支 → 申/戌/丑/巳。

**p46–47完整课**：
- 甲午日，丑将戌时：offset=+3。
- 甲寄寅，四课逻辑序：①巳/甲 ②申/巳 ③酉/午 ④子/酉。
- 下贼上候选上神：②申（阳）、③酉（阴）；甲阳日用比用得初申，中亥，末寅。
- 戌时夜占、甲日夜贵乘天盘未；未在地盘辰，贵人顺行。天盘申乘腾蛇、亥乘勾陈、寅乘白虎；三传`申亥寅`与配将`腾蛇/勾陈/白虎`。
- 快法与完整算法结果应该一致，所有投影值可以书页校核；图片用书中单字天将作为源证，UI用双字全称。

## 源书勘误候选

p46“丑和戌都是四孟神”与作者此前四孟寅巳申亥、四季辰戌丑未的明示分类不符。属于**书内字词疑误`DLR-OPEN-0015`**，不影响二者同为四季的+3相位算例。不可默默把原页改成“季”，异版需单独验证。

今后若正式启动本项目确定性核心，可根据上述向量测试“心算法／索引法”一致性以及三层展示：十二宫、四课和三传的天将与支神一致；课体候选与初传计算原因可追踪。**当前没有创建任何生产引擎、回归测试或修改《天问》核心**；原书规则版本、未决文字及其他学派差异另行建模。
