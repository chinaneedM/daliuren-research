# DUNGAN-DUAL-ALGORITHM-DATA-CONTRACT-R1｜旬遁／五子元遁的两个独立字段

日期：2026-11-22。依据：北海闲人《六壬金针》实体印刷 p36–38（用户提供的私人现代纸本照片）、助手独立复算及用户此前确定的完整术语显示原则。**此为独立算法与UI说明候选，非原书编程规范、非已实现软件。**

## 1. 两种“遁干”不可共用一个未标记值

- **旬遁天干** `xun_dun_stem`：输入当天干支，用干支六十循环查它所在的甲旬；该旬起甲支及后续10支各配甲乙…癸，剩余两个地支处于旬空，旬遁为 `null`。该 null 仅表达“当旬没有配干”，不自动推及其他计算层。
- **五子元遁天干** `wuzi_yuandun_stem`：输入**日干**，按五子元遁歌诀得子支起始天干，再逐支按十干循环配满十二支；本方法不因某日甲旬的空亡而空缺。特别注意选定占时昼夜与五子元遁子支的起时干规则是不同主题，不要把这个配干序列错认为必然实际占课时的时干。
- 两种是独立映射，按当前教材说明不能互相覆盖、互相补缺或混合选择。软件未来可将“主显旬遁／查看五子元遁”设计为视图选项，但必须保留算法标识及原数据。

### 原书印刷反例须永远保留

p37五子元遁四课的局部举例把辰写为**壬**、酉写为**丁**，与本页完整庚子起干支序列“甲辰、己酉”不同。登记 `DLR-OPEN-0014`，保留印刷观察与复算推导并列；**在自动计算测试中不得把未经勘误的局部印字当作正确算法的期望值**，也不得把现代演算悄悄伪称成书上另印“甲、己”。

## 3. 和六亲、天将的不同来源

- `branch_relative(day_stem,branch)`：丁日初传巳火为兄弟（支五行 vs 丁火），不因遁出天干改变。
- `xun_dun_relative(day_stem,xun_dun_stem)`：丁日初传巳的旬干为癸水，癸水克丁火，故“遁官鬼”（原书也简称“遁鬼／暗鬼”）。这只是该遁干相对丁的六亲，并不能代替原来的“巳支为兄弟”。
- `wuzi_dun_relative(day_stem,wuzi_yuandun_stem)`：丁日初传巳的五子元遁干乙木生丁火，若按本书“遁干也可论六亲”的通用五行映射，则衍生父母。**此为我们按该计算方法推导，非作者该页举出的案例**。
- `general_for_heaven_branch[branch]`：天将仍按前节独立映射，天盘支、天将、旬遁干、五子元遁干、支六亲及遁干六亲都必须具有独立标签。
- 用户已经确定软件不为节省1–2字而压缩双字天将名；也明确表示软件无需简写，故**六亲默认也显示完整五类名称**。原书“兄/子/父、鬼/财”等作为历史术语索引，不能直接用作多字段混合计算变量。
