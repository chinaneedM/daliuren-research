# 数字资料检索与公开入库规范 R1

## 检索和保存

首先寻找公开书目、馆藏目录、授权开放的影像、原书公版文本及可依法访问的在线转录。逐项标注 URL、提供者、具体版本、访问条件、版权/使用许可、实际核读范围及核验日期。

**可网上访问不等于可将全文复制到 GitHub。** 仅将确认许可允许的原文/影像入库；其他资料只保存书目、链接、少量合规引用、独立撰写的分析与算法描述。不可绕过登录、付费、技术访问限制。

北海闲人《六壬金针》属于现代著作，不得因为找到 PDF 就直接上传全文。陈公献历史原作可能具有公版属性，但华龄出版社版新增的整理、校注、排版与影像权利边界需另行核实；古籍网络转录还需要具体版本绑定与校勘。

实体书由用户保存；需要精确印次或异文时，可以要求**少量**封面、版权页、目录或疑点页作为核对材料，不能把连续拍照作为日常学习基础。

## 文献记录级别

1. 只发现书目/目录线索（`CATALOG_ONLY`）。
2. 有在线全文但未与具体版本对应（`TEXT_UNBOUND`）。
3. 有版本绑定的转录可读（`TRANSCRIPTION_EDITION_BOUND`）。
4. 有可核读原页或可靠影印证据（`FACSIMILE_VERIFIED`）。
5. 有逐页、逐字可复核比对记录（`COLLATED`）。

任何一项状态都不能自动升级为下一等级。研究判断还需记录使用该文本的具体字句、页码和不确定性。

## 隐私与合规

公开仓库不得上传个人真实生辰、问事隐私、客户资料、版权受限扫描或未经同意的私人内容。不得假称已获得某来源全文、下载权限或授权。
