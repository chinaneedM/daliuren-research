# 大六壬研究路线图 R1

阶段是研究安排，不是强制按页码线性教学。历史全景的纲目与软件设计同步起步，先解决实用的整体问题，复杂异文保留为后续专项。

| 阶段 | 共同研习 / 历史研究 | 软件与验收 |
| --- | --- | --- |
| 0 数字文献与项目基础 | 核实两本书的实体版、合法数字来源和目录；制作主题对照 | 仓库、连续性协议、检查脚本 |
| 1 起课基础 | 干支、时间、月将、天地盘、四课、三传、九宗门及分歧 | 明确输入模型，确定性起课算法和人工对照课例 |
| 2 课式元素 | 十二天将、六亲、旬空、课体、类神、旺衰等 | 按规则版本计算与展示，自动测试 |
| 3 占断实践 | 断法原文、现代解释、实务课例和争议 | 透明说明所用依据，匿名案例与事前/事后记录 |
| 4 史料与传承 | 不同时代典籍、版本与地域学派、术理演变 | 历史来源索引与带证据级别的传承图 |
| 5 深入与扩展 | 版本细校、冲突鉴别、独立复核 | 按证据修订，必要时研究跨项目共享组件 |

## 近期工作的优先次序

1. 完成项目文件和最小检查门槛。
2. 检索《六壬金针》《大六壬指南》可合法访问的在线文献及完整目录；明确书目、具体版本和公开再分发许可边界。
3. 建立两书**主题对应索引**，以实际目录决定首个共同学习专题；避免让用户逐页拍照。
4. 设计排盘输入输出规范及具版本出处的独立测试课例，再实现最小起课核心。

当前不启动相学、风水、奇门、太乙、铁板等新项目。
