# 大六壬软件架构边界 R1

## 模块划分

- **时间与历法输入**：记录时区、日期时间、占时与月将确定方式；任何历法惯例差异显式注明。
- **确定性起课核心**：地盘、天盘、四课、三传、天将等，优先纯函数、明确前提及独立测试向量。
- **规则/流派层**：历史来源与规则版本绑定；不同流派分歧保留候选，不能只因软件方便就默认合并。
- **展示层**：十二支位置与盘面渲染与计算隔离，可在视觉上借鉴《天问》十二宫组件，但需证明语义一致的部分才复用。
- **断课辅助层**：类神、课体、理气与象意等分别展示判断依据、例外和来源，允许并列与冲突。
- **案例记录层**：起课条件、原始课盘、事前分析、后续反馈和匿名化数据相互区分。
- **史料层**：作者、作品、版本、藏本、数字对象、具体页证据和传承关系逐层登记。

## 跨学科独立性

《天问》维持其现有核心边界，当前不改动、不把四柱/紫微术理作为大六壬规则。将来如出现共享干支循环、布局、格式或时间工具，以独立测试和清晰接口为先；不做未经需求验证的大型共享框架。

## 当前能力

尚无起课或断课程序，只有项目文档与状态校验。文档检查成功不代表任何大六壬排盘功能通过测试。
