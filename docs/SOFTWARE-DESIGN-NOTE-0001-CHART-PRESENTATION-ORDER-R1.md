# SOFTWARE-DESIGN-NOTE-0001｜完整课式展示顺序的两种布局（设计候选）

2026-11-18。依据：读者提供《六壬金针》实体印刷第10—11页，以及另一大六壬排盘软件截图。这里只记录自己独立整理的版式事实与设计候选，**不公开原照片、不读取/转录/分析图中用户旧手写笔记、不复制第三方软件截图**。

## 观察事实

1. 实体书第10页将完整课式自上至下写成：**天地盘 → 四课 → 三传**。
2. 实体书第11页作者明确说通常书写成：**三传 → 四课 → 天地盘**，形成上窄下宽「金字塔」式。第10页所示仍是教学实例，不构成唯一要求。
3. 用户发来的第三方排盘软件截图：最上方是带六亲、遁干、支和天将的**三传**（初、中、末自上至下），中间是四列**四课**，下方是带外方内空布局的**天地盘**；也有年月日时、月将、驿马、课体等辅助字段。
4. 两个例题不同：教材印刷例为**乙酉年亥月卯将辰时庚子日**，软件截图显示**丙申日、卯将、酉时**。因此只能直接比版式，不能把二者用作数值相同的课例测试。

## 必须分开的三类顺序

- **计算流程**：月将加时形成天地盘 → 基于干寄宫、日支和天盘取四课 → 按规则选三传 → 配天将、六亲等。算法依赖顺序不随界面变更。
- **页面纵向布局**：教材示例模式为「天地盘/四课/三传」，金字塔模式为「三传/四课/天地盘」。两者仅是渲染顺序，而不是不同的断课流派或不同计算。
- **各块内部语义**：四课有第一至第四课的逻辑编号；书面常自右向左展示，但不能把视觉顺序等同计算编号。三传保持初、中、末身份；整体上下换位不应倒置传次。地盘十二支固定位置与天盘对应关系不应受版式切换影响。

## 软件开发候选（未定稿、不宣称已实现）

1. 计算核心输出一份带来源与规则版本的标准课式数据：时间与月将输入、天地盘映射、按逻辑索引标记的四课、按初中末标记的三传、以及已验证的天将/六亲/遁干等字段。未实现或未核实的字段不得编造。
2. 界面提供两个可切换布局选项：**金字塔（上三传、中四课、下天地盘）**、**教材例式（上天地盘、中四课、下三传）**；具体默认项暂未确定。将来可另有逐步教学模式，不改变正式课式数据。
3. 四课逻辑次序与视觉左右方向分别表示；三传的初中末方向也单列。在手机和电脑、屏幕和打印中允许布局自适应，不改变课值。
4. 测试必须保证：相同课例在两种纵向展示模式间切换时，天地盘位置映射、四课上下神、三传初中末、天将等所有已验证**计算结果完全一致**；只有视觉块的排列变化。
5. 如在不修改《天问》CLOSED 核心的条件下借鉴其十二位置绘图方法，必须另做语义边界和回归测试。

## 证据与未决

- FACT-PHYSICAL：实体 p10 示例与 p11 作者所称通常写法的上下顺序不同。
- FACT-SCREENSHOT：用户示例软件采用三传—四课—天地盘。
- ANALYSIS：展示布局可以与运算依赖、四课横向编号及初中末逻辑顺序解耦。
- OPEN-DESIGN：未来软件默认纵向模式、四课横向布局偏好、打印模式、其他版本课式是否具有不同显示惯例。
- NOT CLAIMED：截图软件算法正确性、所有传统六壬文献都遵循同一排法、项目已有可运行起课程序。
