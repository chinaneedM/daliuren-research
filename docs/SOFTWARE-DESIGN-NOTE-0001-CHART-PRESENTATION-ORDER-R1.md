# SOFTWARE-DESIGN-NOTE-0001｜完整课式展示顺序的两种布局（设计候选）

2026-11-18。依据：读者提供《六壬金针》实体印刷第10—11页，以及另一大六壬排盘软件截图。这里只记录自己独立整理的版式事实与设计候选，**不公开原照片、不读取/转录/分析图中用户旧手写笔记、不复制第三方软件截图**。

## 观察事实

1. 实体书第10页将完整课式自上至下写成：**天地盘 → 四课 → 三传**。
2. 实体书第11页作者明确说通常书写成：**三传 → 四课 → 天地盘**，形成上窄下宽「金字塔」式。第10页所示仍是教学实例，不构成唯一要求。
3. 用户发来的第三方排盘软件截图：最上方是带六亲、遁干、支和天将的**三传**（初、中、末自上至下），中间是四列**四课**，下方是带外方内空布局的**天地盘**；也有年月日时、月将、驿马、课体等辅助字段。
4. 两个例题不同：教材印刷例为**乙酉年亥月卯将辰时庚子日**，软件截图显示**丙申日、卯将、酉时**。因此只能直接比版式，不能把二者用作数值相同的课例测试。

## 必须分开的三类顺序

- **计算流程**：月将加时形成天地盘 → 基于干寄宫、日支和天盘取四课 → 按规则选三传 → 配天将、六亲等。算法依赖顺序不随界面变更。
- **页面纵向布局**：教材示例模式为「天地盘/四课/三传」，金字塔模式为「三传/四课/天地盘」。两者仅是渲染顺序，而不是不同的断课流派或不同计算。
- **各块内部语义**：四课有第一至第四课的逻辑编号；书面常自右向左展示，但不能把视觉顺序等同计算编号。三传保持初、中、末身份；整体上下换位不应倒置传次。地盘十二支固定位置与天盘对应关系不应受版式切换影响。

## 软件开发候选（未定稿、不宣称已实现）

1. 计算核心输出一份带来源与规则版本的标准课式数据：时间与月将输入、天地盘映射、按逻辑索引标记的四课、按初中末标记的三传、以及已验证的天将/六亲/遁干等字段。未实现或未核实的字段不得编造。
2. 界面提供两个可切换布局选项：**金字塔（上三传、中四课、下天地盘）**、**教材例式（上天地盘、中四课、下三传）**；具体默认项暂未确定。将来可另有逐步教学模式，不改变正式课式数据。
3. 四课逻辑次序与视觉左右方向分别表示；三传的初中末方向也单列。在手机和电脑、屏幕和打印中允许布局自适应，不改变课值。
4. 测试必须保证：相同课例在两种纵向展示模式间切换时，天地盘位置映射、四课上下神、三传初中末、天将等所有已验证**计算结果完全一致**；只有视觉块的排列变化。
5. 如在不修改《天问》CLOSED 核心的条件下借鉴其十二位置绘图方法，必须另做语义边界和回归测试。

## 2026-11-18 联合讨论补充：显式地盘与教学可读性（前向追加）

**读者本轮当前口头明确表达的观点，不是对旧手写批注的识读或引用**：相比《六壬金针》在示例中隐藏地盘、要求学习者在脑中补盘的做法，用户更偏好先前提供的排盘软件——完整课式自上而下为三传、四课、天地盘，并明确呈现上下相对的盘位。用户指出隐藏地盘对初学者增加认知负担，尤其容易混淆「月将加时」的参照关系。用户用这次的当前言语将本书示例「卯将辰时」直接解释为：**将天盘的卯对准固定地盘的辰宫**。

**实物印刷的边界**：用户实体书 p11 正文明确教小圆天盘可动、大圆地盘不动，月将地支与占时地盘宫位相对，并称可以不写固定地盘，但必须在意识中保持它的存在；本书 p10 展示的天盘示意本身不显式写地盘。此属于教学表现方式，不能由此推断作者的天地盘算法错误，也不能把当前口头观点称为作者所写。

**设计偏好较上一稿推进**：

1. 将**金字塔式完整课盘（三传／四课／天地盘）**列为用户明确偏好的**默认界面首选方案**；保留教材式作为切换选项，不需要再把两种模式看成完全等权重的未知偏好。仍未实际实现或用户验收 UI。
2. 默认完整盘在十二宫**显式显示固定地盘十二支以及各宫相对应的天盘十二支**，建议使用清晰的上下/内外标签。不得只显示一个没有注明所属盘层的十二支序列，使读者像书中那样必须先凭记忆补地盘。
3. 初学演示提供「月将加时」动作反馈：先固定地盘，标明卯是天盘月将、辰是地盘占时；将天盘卯对准地盘辰，整张天盘随之定位。若将来做交互动画，这只是便于理解的可选展示，不是当前已经开发的功能。
4. 熟练使用者可有「隐藏地盘/精简显示」设置，但**不能成为教学和默认界面的前提**。隐藏的是视觉字符，不是确定性引擎中的地盘状态。
5. 起课测试除了核所有地盘—天盘对应与四课三传外，应分别验显示和隐藏地盘时课式计算一致；特别将「卯将辰时」作为书中人工测试例：地盘辰→天盘卯，地盘巳→天盘辰，地盘申→天盘未。

**尚待实作与验证**：视口大小、颜色辅助标记、交互动画、印刷导出和无障碍标签；本段仅记录用户明确陈述的当前偏好与分析方案，不进行算法或视觉组件开发。

## 2026-11-18 第二次共同研习补充：十干寄宫固定可视标签

在实体《六壬金针》印刷 p12—13 的「庚寄申、申上未」讨论中，读者明确提出：**十干寄宫是固定知识，软件里应当直接可见，便于理解四课的下位怎样由日干借地盘宫位定位**。此为当次口头需求，不涉及旧手写批注。

- 本书纸本十干寄宫表：甲寅、乙辰、丙戊巳、丁己未、庚申、辛戌、壬亥、癸丑。八个不同地盘宫位，巳和未各寄二干。
- 建议固定地盘十二宫始终保留原始地支；**附属标签**可显示寄干（例如申宫附标庚），且根据当日干高亮对应寄宫和其上天盘支。天干寄宫标签不得代替固定地盘地支。
- 第一课示例：日干庚 → 地盘寄宫申 → 上神取天盘未 → 四课显示上未／下庚。必须保留庚、申、未三个不同字段以便解释来源。
- 课程展示可以提供「显示十干寄宫」开关和寄宫口诀查阅，**默认偏向教学可读、标签可见**，但最终视觉细节待软件实际实现、验收后再定；不因开关修改计算。
- 寄宫规则与禄位、羊刃分别建模型，保存教材/版本身份，不将其他学派的不同取法混用为本书规则。
- 详见 study/SESSION-0017-JINZHEN-PP12-13-STEM-LODGING-FIRST-LESSON-JOINT.md；目前软件尚未开发。

## 第14页术语别名的显示层级（2026-11-18 追加）

《六壬金针》印刷 p14 同时用**第一课/干阳/日阳**、**第二课/干阴/日阴**、**第三课/支阳/辰阳**、**第四课/支阴/辰阴**称呼四列，并用「干上神」「支上神」定位两组起始列。读者明确指出，多层别名和「左面」文字使初学者容易在天地盘方位、四课横向列次、干支阴阳之间混淆。

未来建议：默认显示「第一课、第二课、第三课、第四课」的逻辑编号，并提供较小的辅助标签「干阳、干阴、支阳、支阴」；扩展信息中再列历史别称「日阳、日阴、辰阳、辰阴」。术语释义明确「干上神／支上神」是按干寄宫／日支查得的上神，不新增额外课；「左面」仅指传统自右向左排课的邻列。不要按「阳」「阴」词根直接染色为吉凶，也不要把「辰阳」误标为辰时。所有该类显示层级是**界面设计候选、未开发未验收**。原始书页与用户旧手写注释保持私人，不入公开库。
