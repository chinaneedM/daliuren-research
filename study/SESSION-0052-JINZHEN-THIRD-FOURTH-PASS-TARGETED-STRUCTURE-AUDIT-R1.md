## 1. 独立复核与可复算代码

用字面五行映射和显式克向而非上轮五行数值差法，对60日×12位移核查。上神不同值数1/2/3/4为5/115/100/500；非伏吟非返吟多候选全部不比5例；返吟无克六日；同级孟候选戊辰d7一例，均重现SESSION-0051。这里仅为基础结构、并非完整历法课数或实占频率。

进一步限定 d≠0,6，只纳入下贼上优先（无则上克下）后不同候选支唯一，或比用能唯一选出者，共418/720个输入。不以未经裁定的全不比或涉害处理补足样本；此为确定性子集，非完整九宗门实现。初传支同时出现于干二课、支二课的有60个。第一/第三课上神加三传的支集合覆盖全部四课上神加三传的有114个，未覆盖至少一支304个。不是类神实际查找失败率，不包含天将、年命等其他位置/取象。

```python
from collections import Counter
B='子丑寅卯辰巳午未申酉戌亥'; S='甲乙丙丁戊己庚辛壬癸'
L='寅辰巳未巳未申戌亥丑'
E={c:e for e,cs in [('木','甲乙寅卯'),('火','丙丁巳午'),('土','戊己丑辰未戌'),('金','庚辛申酉'),('水','壬癸子亥')] for c in cs}
K=dict(zip('木土水火金','土水火金木'))
counts=Counter(); all_unmatched=[]; fanyin=[]; ties=[]; direct=0; overlap=0; coverage=Counter()
for i in range(60):
    s,b=S[i%10],B[i%12]
    for d in range(12):
        H=lambda x:B[(B.index(x)+d)%12]
        u=[H(L[i%10]),H(H(L[i%10])),H(b),H(H(b))]
        lo=[s,u[0],b,u[2]]
        counts[len(set(u))]+=1
        down=[j for j in range(4) if K[E[lo[j]]]==E[u[j]]]
        up=[j for j in range(4) if K[E[u[j]]]==E[lo[j]]]
        sources=down or up
        can=set(u[j] for j in sources)
        if d==6 and not can: fanyin.append(s+b)
        if d in (0,6): continue
        if len(can)>1:
            same={v for v in can if B.index(v)%2==i%2}
            if not same: all_unmatched.append((s+b,d,sorted(can)))
            pool=same or can # diagnostic only
            if len(pool)>1:
                rank=lambda v:(B.index(v)-d-2)%3
                best={v for v in pool if rank(v)==min(map(rank,pool))}
                if len(best)>1: ties.append((s+b,d,sorted(best)))
            if len(same)==1: can=same
        if len(can)!=1: continue
        x=next(iter(can)); tr=[x,H(x),H(H(x))]
        direct+=1
        overlap+=int(x in u[:2] and x in u[2:])
        coverage[(len(set([u[0],u[2]]+tr)),len(set(u+tr)))]+=1
print(counts,all_unmatched,fanyin,ties,direct,overlap,coverage)
assert (direct,overlap,sum(n for (a,b),n in coverage.items() if a==b))==(418,60,114)
```

## 5. p74–76 与p8、p39–45的结构关系

对于普通递取 x,x+d,x+2d (mod12)，三支互异（排除d0/6）：
d±1为连邻；d±2隔一支；d±3同模3（全孟/全仲/全季）；d±4同模4（三合完整组）；偶数d同阴阳。d±3与d±4互斥，三合各含一个孟仲季。将三合、同阴阳等分别作为象义并不证明是独立证据。特殊取传不自动符合公式，是否命名课体依原文完整条件。
p75的“全财”例列辰戌丑未四支，不能当成单一三传；“全鬼”例列酉巳戌丑，亦有四支且非纯金支，若理解巳酉丑合金须明确局五行而非本五行，戌为额外疑字/例义待核。不能擅改原书，不能以原生六亲与合局六亲混为一栏。
