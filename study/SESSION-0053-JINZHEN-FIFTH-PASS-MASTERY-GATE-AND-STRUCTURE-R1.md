## 2. p76 两旬空与天空组合的结构限制

普通三传 x,x+d,x+2d mod12，且三支互异。六甲旬空每旬为相邻两支。初末的差2d必为偶数，不可能相邻。因此恰有两支旬空必在初中或中末，且 d=1 或11；此为必要条件非充分。特殊取传或重复支不适用此限制。

418个非伏吟返吟、贼克或比用能唯一取支的基础输入中，19个有两传旬空；在p31–32本书昼夜贵人古歌的两种配置中，恰有2个基础输入各有一种昼夜配置使另一个传支乘天空：
- 戊申日 d11，夜贵未、天空丑；四课辰/戊、卯/辰、未/申、午/未；唯一上克下为第二课卯木克辰土，三传卯寅丑。甲辰旬寅卯空。可选符号输入申将酉时，不声称已落实实际历史历日。
- 壬戌日 d1，昼贵巳、天空亥；四课子/壬、丑/子、亥/戌、子/亥；唯一优先下贼上为戌克亥（另有上克下）；三传亥子丑。甲寅旬子丑空。可选符号输入午将巳时，不声称已落实实际历史历日。
以上仅为书内定义可构造性，不为占断效度、完整历法校验或统计频率。重复传位与两旬空+天空为不同检查。

## 3. 干传支/支传干的端点约束

令 a 为日干寄宫序号，b 为日支，H(x)=x+d mod12。干上传支上须 H(H(H(a)))=H(b)，即 2d≡b-a mod12。支上传干上则 2d≡a-b mod12。因左端为偶数，寄宫与日支奇数距离时两者均无解。60甲子恰30日为奇数距离。此必要条件不保证初传确实选到干上或支上，亦不涵盖特殊取传。418确定子集实际端点相符10个；不把这个样本数当作完整九宗门统计。

## 5. 可复算独立代码

```python
from collections import Counter
B='子丑寅卯辰巳午未申酉戌亥'; S='甲乙丙丁戊己庚辛壬癸'
L='寅辰巳未巳未申戌亥丑'
day='丑子亥亥丑子丑午巳巳'; night='未申酉酉未申未寅卯卯'
E={c:e for e,cs in [('木','甲乙寅卯'),('火','丙丁巳午'),('土','戊己丑辰未戌'),('金','庚辛申酉'),('水','壬癸子亥')] for c in cs}
K=dict(zip('木土水火金','土水火金木'))
n=0; dist=Counter(); void2=0; sky=[]; cross=0; odd=0
for i in range(60):
    si=i%10; s=S[si]; b=B[i%12]; a=B.index(L[si])
    odd+=int((i%12-a)%2==1)
    void={B[(i//10*10+j)%12] for j in (10,11)}
    for d in range(12):
        if d in (0,6): continue
        H=lambda x:B[(B.index(x)+d)%12]
        u=[H(L[si]),H(H(L[si])),H(b),H(H(b))]
        lo=[s,u[0],b,u[2]]
        down=[j for j in range(4) if K[E[lo[j]]]==E[u[j]]]
        up=[j for j in range(4) if K[E[u[j]]]==E[lo[j]]]
        c=down or up; can={u[j] for j in c}
        if len(can)>1:
            same={v for v in can if B.index(v)%2==i%2}
            if len(same)==1: can=same
        if len(can)!=1: continue
        x=next(iter(can)); t=[x,H(x),H(H(x))]; n+=1
        if x in u[:2] and x in u[2:]:
            src={j//2 for j in c if u[j]==x}
            dist[tuple(sorted(src))]+=1
        if (t[0],t[2]) in [(u[0],u[2]),(u[2],u[0])]: cross+=1
        if sum(v in void for v in t)==2:
            void2+=1
            assert d in (1,11)
            z=next(v for v in t if v not in void)
            for time,g in [('昼',day[si]),('夜',night[si])]:
                if B[(B.index(g)+6)%12]==z: sky.append((s+b,d,''.join(t),time,g,z))
assert (n,dist[(0,)],dist[(1,)],dist[(0,1)],void2,len(sky),odd,cross)==(418,11,10,39,19,2,30,10)
print(sky)
```
