# SESSION-0005｜同课异事与同课同问：从具体占事到断课可辨识性

2026-11-18。来源：用户就《六壬金针》导论第1页第三段的共同讨论，**不是作者原文，也不是已核对古典课例**。按本书整体研习路线继续；当前不跳至胎产占正式规则，更不宣称客观预测已证实。

## 用户的思考

用户长期研习占卜，提出“问事时刻承载信息”的术理哲学理解：不同术数可将同一时刻映射为不同的卦/课，并借各自断法解释。进一步指出：同一时刻、同一基础课式，有人问婚姻、有人问财；甚至两位女性同一时刻都问胎儿性别，基础课式可能一致，是否仍能根据各自占问条件作出不同判断，是研究占卜师水平和断法差别的重要问题。用户强调：当前无需立即得出答案，整个共同研习正是不断讨论和追问的过程。

## 需要修正的逻辑区别

1. **同课异事**：同一课式，不同占事类别（婚姻与财运），传统六壬可能采用不同类神、取用侧重与解释框架。具体规则须核实原典，不能笼统说“自然能区分”。
2. **同课同事但不同问事者**：两位女性相同时间问胎儿性别，两人的现实结果可以相同，也可以不同；不能由“两人不同”推出“结果一定不同”。若基础课式、占事完全相同，传统断法是否调用年命、行年、主客/事主角色、问占方式、先后顺序等个体输入，**需要逐条查典籍及课例，不能凭空增设规则**。
3. **不可辨识性边界**：若所有实际可用的输入完全相同，确定性算法就应得同样的输出。若事后才以不可记录的“感应/直觉”区别两案，则与可复核规则必须分账记录；不能据此证明信息捕获机制。
4. **术数规则与有效性分离**：记录传统断法如何区分，是文献和软件工程课题；判别真实结果是否超过随机/基线，仍需事前固定规则并与真实反馈核对。尤其“胎儿性别”是思想实验，不能用此类占法代替医疗检查。

## 未来研究的具体问题

- 传统文献中，同课异事如何以类神、占事归属、课传关系取断？
- 同课同事的两个问事主体，哪些身份输入允许变化？规则在实际起课前能否明确，避免事后人为调整？
- 若全部可核输入相同，传统断法有无明文限制/分占规则？
- 可否按“输入条件—类神选择—判断规则—断语—事后反馈”建立匿名课例集，检验断法的一致性与预测表现？
