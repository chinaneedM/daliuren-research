# SESSION-0027｜《六壬金针》p20：贼克与比用之间的判定边界

日期：2026-11-18。本轮用户询问「九宗门是不是按九个名称依次检查，四课不满足贼克就跳比用」。**共同研习准确断点为实体印刷第20页下半《比用法》的触发条件；比用的具体阴阳筛选步骤尚未双方逐段研习。**

## 纸书依据及本轮澄清

第18—20页《贼克法》说明下贼上优先，唯一合格的候选便取该课上神；第20页《比用法》开头明确说：**四课出现几个下贼上，或者没有下贼上而出现几个上克下，才需要比用进一步择用**。由此得到当前教材范围内的条件分支：

| 下贼上数量 | 上克下数量 | 在此阶段的判断 |
|---:|---:|---|
| 1 | 0 | 唯一下贼上的上神发用（本书始入） |
| 1 | 1–3 | 仍取唯一下贼上的上神（本书重审） |
| ≥2 | 任意 | 候选不唯一，进入比用后续筛选 |
| 0 | 1 | 唯一上克下的上神发用（本书元首） |
| 0 | ≥2 | 候选不唯一，进入比用后续筛选 |
| 0 | 0 | 贼克、比用都没有上下相克候选；待原书后续规则，不在此补造去向 |

此表是所见页码的**局部判定示意**，不是完整九宗门决策树。比用属于解决多处相克候选的**后续筛选步骤**，不是所有「不满足贼克」的课都可直接用比用。也不能把书中九宗门的**章节讲述次序**机械当作任一课式按顺序从头挨个判断直至「命中」的全局程序。具体比用阴阳选择、同类候选以及涉害的衔接等候原文展开验证。
