# SESSION-0001｜共同研习：起课输入契约（准备稿，未裁决）

日期：2026-11-18；研究单元：RESEARCH-0002之后首次共同研习准备。**状态：PREPARED / NOT_RULE_VERIFIED**。

## 要解决的不是“先会不会算”，而是“什么输入决定同一张课”

- 占时：输入为哪个地支时辰？由询问者主动指定、提问发生时刻换算，还是采用其他占时惯例？需要保留采用方法，不能悄悄统一。
- 日干支：排课所用干支日与公历日期如何衔接？午夜、子初换日、真太阳时等不同约定不能先验混合。
- 月将：月将与节气/中气的界点关系究竟按哪部书/系统？当日恰在交节/交中气边界时应如何记录？
- 天地盘：在上述输入确定后，地盘十二支固定方向如何定义、月将如何加占时？尚无版次绑定的可复测转换例，不提前写成已证公式。
- 四课三传：需在天地盘、日干寄宫与各派取传法明确之后再研究；不同九宗门规范保留来源分叉。
